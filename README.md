# James Toledo Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript, no build step.

- `index.html` is the whole site
- `media/` holds the talking head videos, their poster images and the n8n screenshot

## Run it on your computer

Open `index.html` in a browser. The videos and fonts work best when the site is online.

## Put it online with GitHub Pages (free)

1. Push these files to a public GitHub repository.
2. In the repository, go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, then save.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

Name the repository `YOUR-USERNAME.github.io` to get the shorter address `https://YOUR-USERNAME.github.io/`.

## Editing

- Text, projects and links are in `index.html`.
- The Drive links in the video section open each video on Google Drive. The files there must be shared as "Anyone with the link".
- To change a video, replace the files in `media/` and keep the same names.
